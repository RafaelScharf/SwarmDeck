Como Iniciar e Testar o SwarmDeck

O SwarmDeck já possui uma versão executável completa com todos os 10 subsistemas integrados (GPU Metal 120 FPS, multiplexador de agentes, detector de bloqueios, socket IPC e notificações nativas). Escolha a forma de execução ideal abaixo.

01. Escolha como Iniciar

Clique nas abas abaixo para ver as instruções de cada forma de execução.

Executar o Aplicativo macOS Standalone

O aplicativo já foi empacotado em modo Release com ícone Retina de alta resolução, assinado com os entitlements necessários (sem sandbox restritivo para permitir execução real de processos PTY e leitura do seu login shell).

1-Click
1. Abrir o aplicativo diretamente: Executa o bundle nativo
open build/Release/SwarmDeck.app
2. Ou via Makefile (atalho conveniente):
make run
3. Se quiser recompilar do zero e gerar novo pacote:
make app && make run
4. Instalar como app definitivo no macOS (via DMG):
open build/Release/SwarmDeck.dmg

Rodar via Swift Package Manager (Terminal)

Ideal para acompanhar logs em tempo real no console (como saídas de debug de redimensionamento do PTY, conexões IPC e eventos do sistema).

Versão de Produção (Arquitetura Modular Completa):
swift run SwarmDeck
Versão Consolidada do Protótipo Inicial:
swift run SwarmDeckPrototype

Controle Remoto via Unix Domain Socket

Com o SwarmDeck aberto em background, ele cria o socket em /tmp/swarmdeck.sock. Você pode controlar seus agentes de qualquer outro terminal ou via Raycast/Alfred.

Testar se o servidor está ativo (Ping):
swift temp/prototypes/swarmdeck_cli.swift ping
Listar todos os agentes ativos e seus estados:
swift temp/prototypes/swarmdeck_cli.swift list
Disparar um novo agente (ex: Claude Code no diretório atual):
swift temp/prototypes/swarmdeck_cli.swift run --preset claude

02. Roteiro de Testes: O que Você Deve Experimentar

Siga este roteiro prático dentro do aplicativo para validar a experiência na prática:

1

Navegação Ultrarrápida por Atalhos

Atalhos ⌘1 a ⌘9

Ao abrir o app, 3 sessões são criadas automaticamente (Zsh, Claude e Antigravity).

👉 Pressione ⌘ 1 para focar no Terminal Shell.
👉 Pressione ⌘ 2 para alternar para o Claude Code.
👉 Pressione ⌘ 3 para alternar para o Antigravity.
2

Criar Nova Sessão de Agente

Atalhos ⌘N ou ⌘T

Adicione quantos agentes desejar de forma paralela e independente.

👉 Pressione ⌘ N ou clique no botão [ + ] no topo da barra lateral.
👉 Escolha um preset integrado (Aider, Claude) ou defina comando customizado.
👉 Selecione a pasta de trabalho desejada pelo seletor de arquivos.
3

Zoom Fluido de Fonte & Troca de Temas

Renderização Metal GPU

Ajuste a legibilidade dinamicamente e troque a paleta de cores em tempo real.

👉 Use ⌘ + e ⌘ - para alterar o tamanho da fonte.
👉 Use ⌘ 0 para resetar para 13pt.
👉 Clique no menu Theme no cabeçalho e alterne entre Tokyo Night, Dracula, Nord ou Catppuccin.
4

Detecção de Bloqueio & Notificações

Deep-Link Nativo

O detector analisa se o processo está em execução (🟢) ou aguardando resposta humana (🔴).

👉 Quando um agente fizer uma pergunta com opções [Y/n], o indicador muda para Blocked: Prompt.
👉 O macOS emitirá uma notificação nativa com som.
👉 Ao clicar no banner de notificação, o SwarmDeck foca diretamente no agente que pediu atenção!
5

Limpeza Rápida de Buffer (Clear)

Atalho ⌘K

Mesmo após logs de milhares de linhas, limpe o histórico visual instantaneamente.

👉 Pressione ⌘ K ou clique no botão Clear no topo do terminal.
👉 Todo o scrollback da sessão ativa é limpo sem interromper a execução do processo.
6

Guarda de Proteção Anti-Acidente

Atalho ⌘W com Confirmação

Evita encerramento acidental de agentes que estejam executando tarefas críticas.

👉 Em uma sessão que esteja trabalhando (🟢), pressione ⌘ W.
👉 Um diálogo nativo alertará: "Session is currently running commands. Terminating it may interrupt active operations."
👉 Permite cancelar ou confirmar o encerramento seguro.

04. Dúvidas Frequentes & Resolução de Problemas

O macOS exibiu aviso de segurança "Aplicativo de desenvolvedor não verificado"? ▼

O pacote foi assinado localmente com assinatura ad-hoc (codesign -s -). Se o Gatekeeper bloquear a abertura pela primeira vez, execute no terminal:

xattr -cr build/Release/SwarmDeck.app

Isso remove o atributo de quarentena do macOS e permite abrir imediatamente.

O comando do agente (ex: claude ou agy) não foi encontrado? ▼

O SwarmDeck inclui o ShellEnvironmentHarvester, que extrai o PATH do seu arquivo ~/.zshrc automaticamente na inicialização. No entanto, o binário do agente precisa estar instalado no seu computador (via npm, pip ou brew).

Caso não tenha o Claude Code ou Antigravity instalados, você pode usar livremente a sessão Standard Shell (/bin/zsh) para rodar qualquer comando normal de terminal.

Como conceder permissão de notificações nativas? ▼

Na primeira inicialização do SwarmDeck.app, o macOS exibirá uma caixa de diálogo nativa perguntando se você deseja permitir notificações. Clique em Permitir para que os alertas de agentes bloqueados funcionem com som e banner.
